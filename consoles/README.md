# The consoles

Every log, by console. A session folder is a date and, where a day had several sessions, a label. `<test>-<model>.txt` is a test's first run in that session and `-2`, `-3` the next ones. `lock.json`, `refresh.json` and `runner.json` record how the test runner started each log. What each console printed about itself is on its own page; `COVERAGE.md` shows which tests ran where.
